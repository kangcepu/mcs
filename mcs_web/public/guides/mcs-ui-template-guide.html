MCS UI Template Guide

Panduan ringkas tampilan Login, Sidebar, Navbar, Profile Page, dan standar font untuk Maintenance Control System.

1. Fondasi desain

Prinsip UI

  • Gunakan permukaan putih, border abu muda, dan ruang kosong yang cukup.
  • Warna biru brand untuk aksi utama dan status aktif.
  • Informasi penting selalu dibaca cepat: judul jelas, label konsisten, dan state kosong/error eksplisit.
  • Icon mendampingi menu atau aksi; jangan menggantikan teks yang penting.

Warna utama

Brand 600 #1B54E0 Brand 500 #2F72F7 Sidebar #111827 Surface #F7F9FC

Border standar: #DCE5F1. Teks utama: #172033. Teks sekunder: #667892.

2. Login page

Struktur

  • Judul: WELCOME MCS.
  • Logo branding berada di tengah; teks Maintenance Control System tampil sebagai teks biasa tepat di bawah logo.
  • Form hanya berisi NIK dan Password. NIK langsung autofocus saat halaman dibuka.
  • Ikon mata: bergaris saat password disembunyikan, tanpa garis saat terlihat.
  • Error login adalah modal tengah berukuran besar: ikon X, Login Gagal, dan Invalid NIK or PASSWORD.
Jangan menyimpan nilai NIK atau password lama pada form. Tekan Enter pada password untuk submit.

State error login

Aturan error

  • Backdrop dibuat gelap dan blur agar fokus pengguna berada pada dialog.
  • Modal berada tepat di tengah layar, berukuran besar, dengan permukaan putih dan sudut membulat.
  • Isi dibuat singkat: ikon X, judul Login Gagal, dan pesan Invalid NIK or PASSWORD.
  • Jangan gunakan toast kecil untuk error login karena mudah terlewat.

3. Sidebar

Aturan

  • Latar #111827, teks menu benar-benar putih, icon abu terang.
  • Menu aktif menggunakan biru brand dan border radius konsisten.
  • Setiap menu memiliki icon Lucide yang relevan.
  • Sub-menu memiliki indentasi dan garis panduan tipis.
  • Sidebar tidak menampilkan scrollbar visual. Akses menu ditentukan permission pengguna.
  • Tombol collapse berbentuk sisi membulat dengan chevron, bukan trapesium.

4. Navbar / App header

  • Header putih dengan border bawah abu muda.
  • Waktu di atas tanggal, keduanya rata tengah. Format tanggal: DD MMM YYYY, contoh 07 Sept 2026.
  • Avatar menggunakan inisial full name. Contoh: Muhammad Khalid Lubis → MKL.
  • Nama yang ditampilkan adalah Full Name; hindari gambar profil pada header.

5. Profile page

Data & perilaku

  • Informasi akun memakai grid dua kolom di desktop dan satu kolom di mobile.
  • Full Name, NIK, email, nomor HP, divisi, dan company bersifat read-only.
  • Nomor HP dan company diambil dari Employee API berdasarkan NIK, bukan wajib ada di tb_user.
  • Bagian Ubah Kata Sandi tetap tersedia: password baru, konfirmasi password, lalu Simpan Perubahan.

6. Standar font

Font UI default

Konfigurasi utama: Inter → ui-sans-serif → system-ui → -apple-system → BlinkMacSystemFont → Segoe UI → Roboto → Helvetica Neue → Arial → sans-serif.

Hanya satu font yang dirender. Browser memilih font pertama yang tersedia: Inter bila terpasang; Windows umumnya Segoe UI bila Inter tidak ada; Android biasanya Roboto; Apple memakai system font/Helvetica Neue; Arial adalah cadangan terakhir.

font-family: Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;

Font branding login

Teks Maintenance Control System di bawah logo login memakai font lokal custom UtamaFont-Regular.ttf melalui Next.js localFont. Font ini khusus elemen branding, bukan font global sistem.
