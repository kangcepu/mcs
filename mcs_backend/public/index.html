Firebase Credential Upload

tb_app_setting (AES-256-GCM)
Selesai
3endpoint baru
  • Sebelumnya JSON service account Firebase cuma bisa dipasang lewat file statis + env FIREBASE_SERVICE_ACCOUNT_PATH (perlu akses server & restart) — kini bisa diunggah langsung dari menu Settings/Branding lewat POST /settings/firebase-credentials (khusus user_management), tersimpan terenkripsi (AES-256-GCM) di tb_app_setting, dan langsung aktif tanpa restart server
  • GET /settings/firebase-credentials hanya mengembalikan status/​project_id/​client_email — private key tidak pernah dikirim balik ke client

  • Validasi upload: file harus JSON valid, type=service_account, dan berisi project_id/client_email/private_key
  • Diuji dengan kredensial sintetis (RSA key hasil-generate sendiri, bukan Firebase asli): upload → aktif langsung, ganti kredensial → langsung terpakai tanpa restart, hapus → otomatis fallback ke file lama
